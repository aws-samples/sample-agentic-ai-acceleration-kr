# 매출 리포트 작성 가이드

AnyCompany 경영진은 정해진 형식의 매출 리포트를 기대합니다. 매출 분석을
요청받으면 **반드시 아래 4개 섹션 구조**로 작성하세요.

## 데이터 수집 순서
1. `query_sales` 도구로 전체 기간 매출 총계를 먼저 확인한다.
2. `top_products` 도구로 상위 상품을 가져온다.
3. 필요하면 `run_sql`로 카테고리·지역·채널별 세부 집계를 한다.
4. 시장 맥락이 필요하면 웹 검색으로 외부 트렌드를 보강한다.

## 리포트 형식 (이 구조를 지킬 것)

### 1. 핵심 지표 (Executive Summary)
- 총매출, 총주문수, 평균 주문 금액(AOV)을 한 줄씩.
- 숫자는 천 단위 콤마, 통화는 "원".

### 2. 카테고리별 실적
- 매출 기준 내림차순 표 (카테고리 | 매출 | 비중%).
- 1위 카테고리를 한 문장으로 강조.

### 3. 베스트셀러
- 상위 5개 상품을 순위와 함께.

### 4. 인사이트 & 액션
- 데이터에서 관찰된 패턴 2~3가지 (예: 주말/월말 매출 변동, 채널 편중).
- 각 인사이트에 대해 실행 가능한 권고 1개.

## 작성 원칙
- 추정하지 말고 **반드시 도구로 조회한 실제 수치**만 사용한다.
- 단정적 어조, 군더더기 없는 한국어 존댓말.
- 마지막에 데이터 기준 기간을 명시한다.
